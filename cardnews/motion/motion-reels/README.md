# 모션 릴스 — 장면 JSON 한 벌로 한 편 (10/12 기본 형식)

원본 릴스의 **훅**과 **CTA 알약**은 원본 프레임을 그대로 쓰고, 그 사이를 대본 전체의 모션 장면으로 채운다.
기준 예시는 `reels-rule-silent.fullmotion.json` (V-E) 이다.

⚠️ 새 장면·새 편을 만들기 전에 **[`STANDARD.md`](STANDARD.md)**(모션 기준 — 폰트·색·이징·화면 규칙)를 먼저 읽는다.

## 사용법

```bash
cd pipeline/cardnews/motion/motion-reels
node check-cta.mjs --measure <원본.mp4> --from <CTA첫프레임> --to <끝프레임>   # 알약 띠 y 실측
node render-full.mjs --scenes <슬러그>.fullmotion.json --stills               # 장면별 중간 프레임만 (빠름)
node render-full.mjs --scenes <슬러그>.fullmotion.json                        # 전체 렌더 + 합성
node review.mjs <결과.mp4>                                                    # 컷/10초 · 경계 점수
node check-cta.mjs --check <결과.mp4>                                         # CTA 띠 밖 bg 단색 · 띠 안 PSNR
```

### 명령 한 줄 (2026-10-06)

`node render-full.mjs --scenes <슬러그>.fullmotion.json` 하나가 아래를 다 한다. 이미 있는 것은 건너뛴다.

1. 기반 영상(`base`)이 없으면 `render-reels.mjs <slug>` 로 만든다(레시피 훅 문구 + `lines/<slug>.txt`).
2. 말 mp3·어절 경계가 없거나 대본·목소리·속도와 어긋나면 `tts-words.py` 로 받는다. 맞으면 다시 받지 않는다.
3. 장면 렌더 → 게이트 → 합성.
4. 드라이브 업로드(기본 켜짐, `--no-drive` 로 끈다): `out/<slug>/upload/<slug>-reels.mp4` 로 복사하고 캡션·AI 라벨 안내와 같이 `<발행일>-` 이름으로 올린다. 발행일이 지난 회차는 올리지 않는다.

🔬 확인(2026-10-06): 고치기 전·후로 V-F 를 렌더 → 클립 9 + 최종본 md5 같다(음성·원본이 있으면 아무것도 안 받는다) · 음성 파일을 빼고 돌리면 받아 오고, 두 번째엔 안 받는다 · V-F(발행일 9/30)는 「지났다 — 올리지 않는다」.

새 편을 만드는 순서는 다음과 같다.
1. 원본에서 훅 끝 프레임과 CTA 첫 프레임을 잰다(밝기가 바뀌는 프레임).
2. `check-cta --measure` 로 알약 띠를 잰다.
3. 장면을 대본 순서대로 적는다.

⛔ 원본(`out/<slug>/`)은 읽기만 한다. 출력 경로가 원본과 같으면 렌더러가 멈춘다.

## 장면 JSON

| 필드 | 뜻 |
|---|---|
| `slug` · `base` · `script` · `recipes` · `fps` · `out` | 원본 릴스 · 대본 · 레시피 · 출력 이름 |
| `hook.from/to` | 원본 훅 프레임 범위(실측 근거는 `_measured`) |
| `cta.from/to` · `cta.mode` · `cta.band.y0/y1` | 기본 `band`: 알약 띠만 떼어 palette `bg` 단색 위에 얹는다(터미널 글자 안 샘). `frames` = 원본 통째 |
| `groundRule` | 바탕 교대 규칙(아래) |
| `minRead` | 글자마다 완전히 보여야 하는 최소 시간(초). 기본 0.6 |
| `scenes[]` | `type` · `dur` · `lines`(출처 줄 번호 또는 레시피 필드) · 타입별 글자 필드 |

## 게이트 (하나라도 걸리면 렌더가 멈춘다)

1. **글자 출처**: 모든 글자 필드가 대본 줄 또는 레시피(`hookBadge`·`hookText`·`hookSub`·`outro`·`title`·`cmd`)에 있어야 한다.
2. **선언 안 된 글자**: 그려진 글자는 다음 셋 중 하나여야 한다.
   - 선언된 글자
   - 선언된 글자의 일부(타이핑 중 앞부분 · 줄바꿈 조각)
   - 카운터 중간값
3. **모양 옵션**: 개수·분포를 그림으로 암시하는 옵션은 **기본 끔**이다. 켜면 출처 필드가 필수이고, 그 출처 글에 그 숫자가 있어야 한다.
   - `timeline.marks` ← `marksSource`
   - `setSplit.n` ← `nSource`
   - `setSplit.apart` ← `apartSource`
   - 출처 형식: `"대본 N줄"` 또는 `"레시피 필드"`
4. **글자 구역**: 모든 프레임의 글자 잉크가 `safe-zone.mjs` `글자안전()` 안에 있어야 한다(`검사글자()` 로 판정).
5. **WCAG 대비**: 모든 글자가 밑색(바탕 또는 칩)에 대해 **4.5:1 이상**이어야 한다(`palette.mjs` 색만 쓴다).
6. **읽을 시간**: 선언된 글자마다 불투명도 0.9 이상 · 90% 이상 드러난 상태로 `minRead` 초 이상 보여야 한다.
7. (사후) `review.mjs` 로 경계 점수, `check-cta.mjs --check` 로 CTA 띠 밖이 bg 단색인지 본다.

## 바탕 교대 규칙

- `alternate`, `first: "accent"`. 훅이 어두우니 첫 장면은 `accent` 이고, 한 장씩 번갈며, **장면 수는 홀수**로 둔다. 그러면 마지막 장면(accent)과 CTA(어두움) 사이 경계도 잡힌다.
- 근거(2026-09-29 실측): 어두움→어두움 경계 점수 0.10–0.23, 어두움↔accent 경계 1.000. 같은 바탕이 이웃하면 그 경계는 하드컷으로 안 잡힌다. 그러면 렌더러가 경고한다.
- 장면별로 `ground: "dark" | "accent"` 를 직접 지정할 수 있다.
- `accent` 바탕: 글자는 `onAccent`, 나쁜 값(danger)은 `bg` 칩 위에 얹는다(accent 위 빨강은 대비가 안 나온다).

## 장면 타입

| 타입 | 글자 필드 | 쓰임 |
|---|---|---|
| `command` | `cmd` · `result` | 명령 한 줄 타이핑 → 결과 숫자. 프롬프트는 모양(꺾쇠)이다 |

| `numberPunch` | `a{label,value}` · `b{label,value}` | 값이 굴러 바뀜(a → b). `switchAt` · `switchLen` |
| `contrastCounter` | `title`? · `rows[{label,value,tone}]` · `foot` | 두 줄이 같이 세다가 한 줄만 오름 |
| `kinetic` | `words[]` | 낱말이 한 줄씩 올라옴. `mute`(평평한 파형) · `wave:"pulse"`(심장 박동) · `fitW` |
| `strike` | `words[]` · `strike` | `strike` 번째 낱말에 줄을 그음 |
| `stamp` | `a` · `b` | 달력 한 장 넘김 + 체크 |
| `glitchEquation` | `caption` · `eq` · `reveal` | 등식이 깨지고 reveal 이 뜸 |
| `setSplit` | `caption` · `sub` · `eq` | 두 묶음이 겹침. 점(`n`·`apart`) 기본 끔 |
| `verdict` | `a` · `b` · `hi` | 반전 결론. `hi` 가 칩으로 박힘 |
| `limits` | `head` · `items[]` | 한계 카드(낱말 단위 줄바꿈) |

대본 줄을 쪼개 쓰면 조각마다 `lines` 의 줄에서 찾아진다. 출처 목록은 렌더 로그 첫 부분에 찍힌다.

## 박자 `timing` — **center 기본값 `hold`** (2026-09-30 사용자 결정)

- `hold`: 장면이 설계 길이보다 길어지면 **등장·전환 박자는 설계 길이 그대로**, 남는 시간은 끝에서 머문다. 짧아지면 예전처럼 비율.
  - 근거: 모션그래픽 주문 사전 `compose.js` — *"길게 늘릴 때 «머무는 줄»만 늘리고 등장 속도는 그대로, 줄일 때는 전체를 비율대로."*

  - 말 큐로 준 초(`switchSec` 등)는 절대 초라 영향이 없다.
- `scale`: 예전 방식(박자가 장면 길이에 비례). `layout: left`(V-D·V-E)의 기본값.
- 우선순위: 장면 `timing` → 장면 JSON `timing` → layout 기본값.

## 읽을 시간의 조각 판정 (2026-09-30 고침)

- 글자가 줄바꿈돼 통째로 안 그려지면 조각으로 판다. **다른 조각에 포함되는 조각은 뺀다**(타자 중 앞부분 · 한 글자씩 번지는 글자). 남은 **최대 조각**들 중 최소값을 쓰고, 최대 조각들이 **원문 전체를 덮지 못하면 0** 으로 친다.
- 📌 고친 이유: 예전엔 모든 조각의 최소라서, 줄바꿈된 글을 타자로 치면 1프레임짜리 앞부분이 최소가 돼 **완성된 줄이 2초 보여도 0.04s** 로 막혔다(`termCard`·`chatUI`·`innerThought`).
- 🔬 고친 뒤 회귀(2026-09-30): V-F 통과 · 읽을 시간 표가 고치기 전과 **한 글자도 안 다르다**. V-E(left) 통과 · 클립 13개가 이전 기준 클립과 **md5 같다**(left 코드 무변경 확인).

- `center` (2026-09-29 3차 개정 — 줄마다 규칙 · 화면 채움)
  - 버튼 열은 프레임 **y 896 아래에만** 있다(`safe-zone.mjs` 측정 `우측버튼열_시작y` − `우측버튼열_여유` = 848, 1080 기준).
  - **줄마다 규칙**: 줄 상자 바닥이 848 위면 오른쪽 끝 ≤ 1004, 아래면 ≤ 760. 글자 블록 전체는 y 154–1270 안에 둔다. 게이트는 줄마다 `검사글자({…, 세로반영: true})` 와 같은 경계로 모든 프레임을 본다.
  - 블록 가로 중심은 **x 540**(프레임 중심)이고, 글자는 가운데 정렬한다.
  - **배율과 세로(위치 우선 · 2026-09-29)**: 배율 1.6–1.0 을 모두 시험해 **블록 중심이 y 960 에 가장 가까운 배율**을 고르고, 같으면 큰 배율을 쓴다.
    - 하한은 1.0 이다. 1.0 에서도 안 들어갈 때만 0.92 → 0.76 을 본다. 줄 수는 늘리지 않는다.
    - 넓은 줄(폭 > 440)이 있으면 그 줄 바닥이 848 위에 있어야 해서, 그런 장면은 배율 1.0 에서 가장 낮게 온다.
  - 판정은 장면의 **모든 프레임 × 모션 블러 표본**을 시험으로 그려서 한다.
    - 가로 폭은 **클립 전** 상자로 본다. 구역 클립에 잘린 글자가 들어간 것처럼 보이지 않게 하려는 것이다.
    - 글리치 조각과 색 번짐 사본(일부러 어긋난 것)은 예외로, 클립 후 상자로 본다.
  - 결정은 렌더 로그 「장면 구역」과 `bounds.json` 의 `zoneDecisions` 에 남는다(배율 · 블록 높이 · 중심 · 채움 띠).
  - **채움 띠**: 블록 아래 ~ 1270 이 140px 넘게 비면 글자 없는 장식(격자 강조 + 모서리 괄호 + 훑는 선, x 540 대칭)을 켠다. 개수·분포를 암시하지 않는다.
  - **떠 있는 장식**은 x 540 대칭, **글자에 붙은 장식**은 글자를 따른다.
  - 장면 JSON 에 `"fill": false` 를 주면 2차 규칙(위쪽 구역 가운데)으로 돌아간다.
- `left`: 예전 구도(V-D·V-E). 장면 JSON 에 `"layout": "left"` 로 고정해 뒀다. 예전 검사를 쓰고, 그 코드는 안 바뀐다(클립 md5 로 확인).
- 우선순위: 장면 JSON 의 `layout` → 없으면 `center`. 명령줄 `--layout` 으로 덮을 수 있다.
- 계측: `node render-full.mjs --scenes <json> --stills --layout center --at end` → `layout-*.json`
- ⚠️ 1270 아래(프레임 아래 1/3)는 캡션·프로필 자리라 글자도 채움 띠도 두지 않는다. 그래서 1초 시트에서 그 띠는 모든 모션 장면에서 비어 있다.

## 틀 표시 `marks` — **기본값 `edge`** (2026-09-29 사용자 결정)

- `edge`(기본): 모서리 괄호는 **프레임 가장자리**(x 40·1040 · y 40·1880)에만 둔다. 채움 띠 괄호는 없고, 신호등 점은 좌상단 가장자리에 둔다.
- `none`(**후보**): 괄호·채움 띠 괄호·신호등 점을 모두 없앤다(격자 강조·훑는 선은 남는다). 예시: `reels-rule-silent-voice-nomark.mp4`
- `scene`(**V-D·V-E 호환용만**): 글자 구역 모서리 괄호 + 채움 띠 괄호 + 신호등 점. 두 JSON 에 `"marks": "scene"` 으로 고정했다.
- 우선순위: 명령줄 `--marks` → 장면 JSON `marks` → `edge`. 출력 이름은 `--out` 으로 가른다(클립·스틸 이름에도 marks 가 붙는다).

## 맨 아래 장식 `fillBottom` — 기본 끔 (사용자가 예를 보고 정한다)

- `true`(또는 `--fill-bottom`): 캡션·프로필 자리(y 1270–1920)를 **글자 없는 옅은 장식**으로 채운다. 장식은 격자 · 연속 파형 · 훑는 선이고, 장면 바탕과 같은 계열이다.
- ⛔ 글자 없음. 셀 수 있는 모양(막대·점)이 없어 개수·분포를 암시하지 않는다. 앱 캡션이 그 위에 뜨므로 불투명도는 7–16% 로 낮게 둔다.
- 실측(2026-09-29): 그 구간 평균 밝기 변화는 장면별 −0.8 ~ +1.1(0–255)이다. 예시: `reels-rule-silent-voice-fillbottom.mp4`

## CTA 화면 `cta.mode`

- `sting`(V-F): 브랜드 스팅 파일(`make-brand-sting.mjs` 산출, 읽기만)을 붙인다. CTA 말이 더 길면 **스팅 마지막 프레임을 말 끝 + `tail`** 까지 정지한다.
- `band`(V-E): 원본 알약 띠만 bg 위에 얹는다.
- `frames`: 원본 CTA 통째.
- `voice.cta.at` 에 큐(예: `{ "cue": "speechEnd", "plus": 0.13 }`)를 주면 CTA 말이 본 말 끝 직후에 시작해 앞 장면(한계 카드) 위에 깔린다.
- 확인: `check-cta.mjs --check`. 스팅 모드면 스팅 원본(+정지)과 PSNR 을 비교한다.

## 말이 있는 판 (V-F · `reels-rule-silent.voice.json`)

```bash
python tts-words.py <말대본.txt> voice/<이름>.mp3 voice/<이름>.words.json [voice] [rate]   # 음성 + 어절 경계
node render-full.mjs --scenes <슬러그>.voice.json
```

- **말 대본은 한 글자도 안 바꾼다.** 어절 경계 JSON 의 `text` 가 대본 파일과 다르면 렌더러가 멈춘다. 목소리·속도가 다를 때도 멈춘다.
- edge-tts CLI 의 `--write-subtitles` 는 **문장 경계만** 준다. 쉼표로 이은 한 문장이면 큐가 1개뿐이다. 그래서 설치된 라이브러리의 `boundary="WordBoundary"` 로 받는다(`tts-words.py`). 절 = 쉼표·마침표 토막.
- **장면 길이는 말이 정한다.** 두 필드로 정한다.
  - `start` / `end`: 큐 `{ "cue": "clause:N" | "clause:N:end" | "word:어절" | "speechEnd", "plus": 초, "min": 초 }`. 컷 프레임은 내림이라 컷이 말보다 조금 먼저 온다.
  - 장면 안 박자: `switchSec` · `countSec` · `popSec` · `bSec` · `hiSec` · `breakSec` 에 큐를 쓰면 그 장면 기준 상대 초가 된다. `min` 으로 읽을 시간 하한을 건다.
- 말보다 글자가 많아 읽을 시간 게이트(≥0.6s)에 걸리면, **쉼을 넣지 말고 장면을 합친다.** 합친 이유는 장면의 `_merge` 에 적는다.
- **CTA 말**이 알약 띠보다 길면 마지막 프레임을 복제해 정지 구간만 늘린다(페이드는 원본 그대로).
- **효과음** (`sfx-cuts.mjs`, 전부 코드로 합성)
  - 훅: `make-hook-sfx.mjs` 의 `typing` 을 재사용한다. 이음새 임팩트가 훅→첫 장면 컷에 떨어진다.
  - 하드컷마다 `tick` 이 붙는다.
  - 장면별로 `sfx: [{ kind: "impact" | "glitch", at: 큐 }]` 를 쓸 수 있다.
  - 덕킹: 말 구간(**파형 −40 dBFS 기준**)에서 `duckDb`(기본 −14). 어절 경계는 들리는 시작보다 80–100ms 이르다.
- **음량**: 효과음과 말을 섞은 뒤 `loudnorm` 2패스(linear)로 −14 LUFS · 트루피크 −1.5 dBTP 에 맞추고, 최종본을 `ebur128` 로 다시 잰다.
- ⛔ **합성 음성 판은 `voice.aiVoice: true` 가 필수다**(AI 라벨 대상). mp4 `comment` 메타와 `bounds.json` 에도 남는다.

## 파일

- `render-full.mjs`: 전체 모션
- `render-cuts.mjs`: 원본 위에 컷을 덮거나(replace) 끼운다(insert)
- `lib.mjs`: 게이트 한 벌(두 렌더러가 같이 쓴다)
- `cuts.html`: 장면 라이브러리. 계약은 `window.frame(t)` 하나
- `voice.mjs` · `sfx-cuts.mjs` · `tts-words.py`: 말 타이밍 · 효과음 · 음성+어절 경계
- `review.mjs` · `check-cta.mjs` · `check-insert.mjs`: 사후 확인
